# 四维评分系统优化设计

## 概述

优化用户初始化四维评分系统，支持更丰富的图片上传类型，并通过 AI 综合分析实现更智能的评分。

## 设计目标

1. 支持多种图片类型：头像、正面肖像图、正面图、侧面图
2. 旷视 API 专注分析面部肤质（用肖像图）
3. AI 综合分析所有信息给出四维评分
4. 无图片时使用问卷模式，同样由 AI 评分
5. 评分采用软引导策略，让 AI 自主判断

## 数据模型变更

### UserProfile 新增字段

```python
avatar_url: str           # 头像（仅显示，不参与评估）
portrait_photo_url: str   # 正面肖像图（旷视肤质分析）
front_photo_url: str      # 正面图（AI分析体态）
side_photo_url: str       # 侧面图（AI分析体态）
```

## 评估流程

```
用户上传图片（可选）
    ↓
┌─────────────────────────────────────┐
│ 有肖像图/正面图/侧面图？            │
│   ├─ 是 → 调用旷视（用肖像图）      │
│   │       → 综合评分模式            │
│   └─ 否 → 问卷模式                  │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ 综合评分模式：                      │
│   输入：                            │
│     - 旷视肤质结果（如有）          │
│     - 正面图 + 侧面图（如有）       │
│     - 身体数据（身高、体重、BMI等） │
│   输出：四维评分                    │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ 问卷模式：                          │
│   输入：                            │
│     - 四个问题的回答                │
│     - 身体数据                      │
│   输出：四维评分                    │
└─────────────────────────────────────┘
```

## 评分 Prompt 设计

### 综合评分模式（有图片）

```
你是一个专业的健康评估AI。请根据以下信息，为用户评估四个维度的初始分数（0-100分）。

【身体数据】
- 身高：{height}cm
- 体重：{weight}kg
- BMI：{bmi}（{bmi_label}）
- 年龄：{age}岁
- 性别：{gender}

【肤质分析结果】
- 皮肤类型：{skin_type}
- 肤质评分：{skin_score}/100
- 存在问题：{issues}

【评分标准】
- 运动维度：BMI>25属于超重，运动评分应偏低；体态显示缺乏运动则更低
- 饮食维度：BMI>25说明饮食可能不健康，评分应偏低
- 睡眠维度：有黑眼圈、眼袋、疲惫迹象说明睡眠不足，评分应偏低
- 外貌维度：肤质差、形象不整洁则评分偏低

请根据图片和数据综合判断，返回JSON：
{"exercise": 分数, "diet": 分数, "sleep": 分数, "appearance": 分数}
```

### 问卷评分模式（无图片）

```
你是一个专业的健康评估AI。请根据以下信息，为用户评估四个维度的初始分数（0-100分）。

【身体数据】
- 身高：{height}cm
- 体重：{weight}kg
- BMI：{bmi}（{bmi_label}）
- 年龄：{age}岁
- 性别：{gender}

【用户自述】
- 运动：{exercise_answer}
- 饮食：{diet_answer}
- 睡眠：{sleep_answer}
- 外貌：{appearance_answer}

【评分标准】
- 根据用户自述内容合理评估，回答越详细、习惯越好，分数越高
- BMI>25属于超重，运动/饮食评分应适当偏低

请返回JSON：
{"exercise": 分数, "diet": 分数, "sleep": 分数, "appearance": 分数}
```

## 前端界面设计

### Onboarding 页面流程

1. **欢迎页**：介绍系统
2. **身体数据输入**：身高、体重、年龄、性别
3. **图片上传**（可选）：
   - 头像（仅显示）
   - 正面肖像图（旷视分析）
   - 正面图（AI分析体态）
   - 侧面图（AI分析体态）
4. **问卷**（如果没上传评估图片）：
   - 运动：你每周运动几次，一次运动多长时间？
   - 饮食：你的饮食规律如何？
   - 睡眠：你通常几点睡觉，每次睡几个小时？
   - 外貌：你平常是否有注意打理自己，你对自己的外在形象满意吗？
5. **确认页**：显示已填信息
6. **评估中**：显示当前使用的分析方式
7. **完成**：跳转到仪表盘

### 加载动画显示

评估过程中显示当前使用的分析方式：
- "正在使用 旷视肤质分析..."
- "正在使用 AI综合分析..."
- "正在使用 问卷评估..."

## 后端 API 变更

### 上传接口

```
POST /api/users/me/photos/upload
- avatar: File（头像）
- portrait_photo: File（正面肖像图）
- front_photo: File（正面图）
- side_photo: File（侧面图）
```

### 评估接口

```
POST /api/users/me/evaluate
Request:
{
  "height_cm": float,
  "weight_kg": float,
  "age": int,
  "gender": str,
  "questionnaire": {
    "exercise": str,
    "diet": str,
    "sleep": str,
    "appearance": str
  } | null
}

Response:
{
  "message": "evaluation complete",
  "scores": {
    "exercise": float,
    "diet": float,
    "sleep": float,
    "appearance": float
  },
  "skin_analysis": {...} | null,
  "skin_source": "faceplusplus" | "ai" | "fallback" | "none",
  "eval_mode": "photo" | "questionnaire"
}
```

## 降级策略

1. **图片评分降级**：
   - 有图片 → AI综合评分
   - AI失败 → 问卷模式（提示用户填写问卷）
   - 问卷也失败 → 默认50分

2. **肤质分析降级**：
   - 旷视API → 系统AI → 保底规则
